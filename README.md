# Flashcard Learning App

## Project description

A polished, responsive flashcard app for reviewing HTML, CSS, JavaScript, and web development fundamentals. Flip each card to reveal its answer, track your deck progress, and study in the order that works for you.

## Features

- Ten predefined frontend and web development flashcards.
- Smooth 3D card flip with clearly distinguished question and answer sides.
- Previous and Next navigation, with boundary buttons disabled.
- Live card count, progress bar, and completion percentage.
- Shuffle the deck and restart from the first card.
- Left and right arrow-key navigation.
- Responsive layouts, keyboard focus styles, and reduced-motion support.

## Technologies used

- HTML5
- CSS3
- Vanilla JavaScript

## How to run the project locally

1. Download or clone the project.
2. Open `index.html` in a modern web browser.

No build step or package installation is required. The page uses Google Fonts when an internet connection is available and falls back to system sans-serif fonts otherwise.
